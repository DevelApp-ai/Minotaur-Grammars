# TypeScript

TypeScript (ES2022 + type system) grammar for the Minotaur parser platform (authored for issue #8).

Authored from scratch for DevelApp (Minotaur-Grammars issue #8) and licensed
under MIT. Based on the public language specification; see the grammar header
for details. Coverage is a well-formed high-level subset suitable for parsing
and projection; not every edge case of the specification is modeled.
