# Benchmark corpus (issue #192)

Curated grammars + reference input corpora for the cross-repo measurement
issues (research-article support). Everything here is committed and
reproducible; the synthetic size-class grammars are regenerated by a
committed script.

## Grammar -> measurement issue mapping

| Content | Location | Consumed by |
|---|---|---|
| JSON grammar | `programming-languages/json` | Minotaur#130 (LLVM parsing-speed), engine #101/#104 |
| C grammar | `programming-languages/c17` | Minotaur#130 |
| XML grammar | `programming-languages/xml` | Minotaur#130 |
| FIX 4.2/4.4 subset grammar | `networking/fix44` | Minotaur#132 (FIX/HFT case-study pilot) |
| Apache/Nginx combined log grammar | `system-output/apache-access-combined` | Minotaur#132 (log analytics pilot) |
| Syslog grammar | `system-output/syslog` | Minotaur#132 |
| JSON-lines logs | `programming-languages/json` over `benchmarks/inputs/logs/app.jsonl` | Minotaur#132 |
| Size-class grammars 20/60/180/320 rules | `benchmarks/synthetic/rules-*` | Minotaur#131 (compile-time by size), Minotaur#126 (DSL workbench: 15-25 / 50-80 / 150-200 / 300+ classes) |

## Reference inputs

`benchmarks/inputs/` holds one small and (for JSON) one large sample per
format: `json/config.json`, `json/large.json`, `c/sample.c`, `xml/pom.xml`,
`fix/session.fix` (SOH-delimited messages), `logs/access.log`,
`logs/syslog.log`, `logs/app.jsonl`.

## Provenance and licenses

- FIX, Apache-combined and Syslog grammars: written for this repo (DevelApp),
  MIT (see each folder's LICENSE). FIX field semantics: FIX 4.2/4.4
  specification (public). Log formats: Apache combined / RFC 5424 (public).
- Synthetic grammars: generated by `benchmarks/synthetic/gen_synthetic.py`
  (deterministic; regenerate with `python3 benchmarks/synthetic/gen_synthetic.py`).
- JSON/C/XML grammars: existing repo grammars (MIT), reused in place.

## Running the measurements

- Engine-side benchmarks: `src/DevelApp.Benchmarks` in
  DevelApp-ai/ENFAStepLexer-StepParser (engine #101/#104); the grammars CI
  job `grammar-repository-tests` already lexes/parses every grammar and
  Conformance.txt here in GreedyLongestMatch mode.
- App-side: `Minotaur.Benchmarks` in DevelApp-ai/Minotaur (Minotaur#126-#134,
  live-editing harness from #197 at `docs/measurements/issue-196/`).
- Point harnesses at this checkout via `MINOTAUR_GRAMMARS_DIR`.
