# Minotaur-Grammars

**The consolidated grammar library for the DevelApp ecosystem**

The repository is the **single home for grammar definitions** used by
[Minotaur](https://github.com/DevelApp-ai/Minotaur),
[ENFAStepLexer-StepParser](https://github.com/DevelApp-ai/ENFAStepLexer-StepParser),
and grammars distributed via
[Minotaur-Marketplace](https://github.com/DevelApp-ai/Minotaur-Marketplace).

For the full project overview, see the
[README](README) — this page is the documentation hub for the site.

## 📦 Grammar categories

Every grammar lives in its own folder with its metadata and license, grouped
by category (browse them on GitHub):

- [Programming languages](https://github.com/DevelApp-ai/Minotaur-Grammars/tree/main/programming-languages) — including the optional `Labyrinth.extension` overlays (SAST pattern operators)
- [Natural languages](https://github.com/DevelApp-ai/Minotaur-Grammars/tree/main/natural-languages)
- [Compiler-compilers](https://github.com/DevelApp-ai/Minotaur-Grammars/tree/main/compiler-compilers)
- [Postal codes](https://github.com/DevelApp-ai/Minotaur-Grammars/tree/main/postal-codes)
- [Specification-first (SpecTree)](https://github.com/DevelApp-ai/Minotaur-Grammars/tree/main/specification-first)
